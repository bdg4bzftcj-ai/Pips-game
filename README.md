# Spotlock

A daily domino logic puzzle. Place every tile from your tray onto the board so
each coloured region's rule holds: an exact sum, less than, more than, all
equal, or all different.

- **Three puzzles a day** (easy, medium, hard) with an **archive** from
  1 January 2025. All puzzles are generated by this project's own generator;
  none are copied from other games.
- Works on **phone and desktop**: drag tiles, or tap a tile and then a square.
  Tap a placed tile to turn it. Undo, clear, show solution, timer, streaks.
- **Progress saves** on the device (localStorage).
- **Works offline** once loaded (service worker), and installs to the home
  screen as a PWA.
- **Ready to wrap as an iOS app** with Capacitor (see below).

## Project layout

```
www/                  the whole app (static files, no build step)
  index.html
  css/app.css
  js/generator.js     puzzle generator + solver (also runs in Node)
  js/app.js           UI, archive, input, persistence
  data/archive.js     pre-generated daily puzzles (2025-01-01 → 2026-12-31)
  sw.js, manifest.webmanifest, icons/
scripts/
  build-archive.js    regenerates / extends data/archive.js
  build-single.js     bundles everything into one HTML file
  make-icons.py       redraws the icons
capacitor.config.json iOS wrapper config
```

Dates after the end of the archive are generated on the fly with the same
seeded generator, so the game never runs out. To bake in more years:

```bash
node scripts/build-archive.js 2025-01-01 2028-12-31
```

Don't regenerate dates that people have already played. Changing the generator
or the start date changes those puzzles, and saved progress would no longer
match.

## Run it

```bash
npm run serve              # http://localhost:8080
```

Or open `dist/spotlock.html` after `npm run single`. It's a single file that
works with no server at all.

## Put it on your phone (no App Store)

1. Push to GitHub, then go to **Settings → Pages → Source: GitHub Actions**.
   The included workflow publishes `www/` on every push to the default branch.
2. Open the Pages URL in Safari on the iPhone → Share → **Add to Home Screen**.
   It launches full-screen, works offline, and keeps your progress.

## Make it a real iOS app (needs a Mac with Xcode)

```bash
npm install
npx cap add ios        # creates the ios/ Xcode project from www/
npx cap open ios       # opens Xcode
```

In Xcode, choose your Apple ID team under *Signing & Capabilities*, plug in
the phone and press Run. A free Apple ID lets you install it on your own
device; the build expires after 7 days and you re-run it. A paid developer
account removes that limit. After changing anything in `www/`, run
`npx cap sync ios`.
